# VAYNORA Development Roadmap

The order in which we should develop VAYNORA.

Don't begin by creating the whole city. First, create a character who can move around a basic environment. Then add gameplay systems one by one.

## Phase 1 – Player foundation

**Start here.**

- Third-person character
- Walking and running
- Jumping
- Camera rotation
- Mobile joystick
- Basic animations

**Deliverable:** A character you can control in a 3D environment.

## Phase 2 – World foundation

- Terrain and roads
- Buildings
- Lighting and sky
- Trees and environmental objects
- Collisions and boundaries

**Deliverable:** A small explorable neighborhood.

## Phase 3 – Interaction system

- Interact with objects
- Open doors
- Collect items
- Talk to NPCs
- Display interaction prompts

**Deliverable:** A world that responds to the player.

## Phase 4 – Memory Vision

- Activate and deactivate ability
- Reveal hidden objects
- Switch selected environment objects between past and present
- Add visual effects and sound

**Deliverable:** VAYNORA's signature gameplay mechanic.

## Phase 5 – Missions and puzzles

- Quest management
- Dialogue system
- Puzzle mechanics
- Rewards and collectibles

**Deliverable:** First complete adventure mission.

## Phase 6 – Game interface

- Main menu
- Pause menu
- Quest journal
- Inventory
- World map
- Settings

**Deliverable:** A complete playable game interface.

## Phase 7 – Mobile optimization

- Android performance
- iOS performance
- Touchscreen controls
- Graphics settings
- Saving and loading

**Deliverable:** A mobile-ready prototype.
